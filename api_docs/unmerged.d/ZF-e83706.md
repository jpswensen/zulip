**Feature level ZF-e83706**

* [`GET /server_settings`](/api/get-server-settings): Added
  `push_notifications_direct` boolean, indicating whether the server
  delivers APNs/FCM push notifications directly to the mobile app using
  its own credentials, rather than through the Zulip mobile push
  notification service. Custom-signed mobile clients use this to decide
  whether to register device tokens via the legacy
  [`POST /users/me/apns_device_token`](/api/add-apns-token) endpoint.
